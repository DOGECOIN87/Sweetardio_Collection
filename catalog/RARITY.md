# Rarity table — Sweetardio Collection

Generated by `asset_assessment/build_rarity_table.py` from the token metadata that `build_mint.py --n 4444 --seed 4444` writes — 4444 is the seed the draw gains in `traits/rarity_weights.json` are calibrated against. Regenerate whenever the calibration is re-run or a trait is renamed.

**4444 tokens, all composited.** The 1/1 secret-rare tier is retired to `traits/secret_rarez_retired`, so every token is a character.

Always-present traits (character, background, skin, eyes, mouth) are drawn by calibrated weight and land within ~0.2 points of target — roughly the sampling floor at this supply. Optional traits (arms, footwear, stickers) and the legendary plates are slot-allocated to EXACT counts.

Every value below is read straight from the shipped token metadata.
